Systèmes par groupes

Un groupe entier par ligne, puis croisement entre les lignes. Aucun croisement entre groupes d’une même ligne. Chaque grille doit réunir exactement 7 numéros distincts.

Sur téléphone, fais glisser chaque ligne vers la gauche pour accéder aux groupes suivants.

Les numéros de la page Bulletin sont recopiés automatiquement dans les groupes, dans l’ordre. Les cases restantes peuvent être complétées manuellement.

Groupes A · D · H · L · P · T · X

La condition compte les groupes choisis lors du croisement, parmi A, D, H, L, P, T et X. Un seul groupe est retenu par ligne. Les autres groupes restent autorisés.

Autres groupes : de haut en bas

Chaque colonne reprend les groupes à la même position sur les lignes. Choisis un minimum de 1 à 7, ou « Sans condition ». Toutes les conditions actives se cumulent.
